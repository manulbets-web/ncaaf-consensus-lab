# v3.5.44 formal architecture-ablation validation

Page 5 now asks where prospective ATS signal disappears rather than searching for another favorable parameter.

The same untouched chronological OOS blocks are evaluated under five architectures:

- A — all historically posting models, equal-weight consensus.
- B — prior Wilson-ranked Top 35, equal-weight consensus.
- C — the single highest prior Wilson-ranked model.
- D — the Top 35 after near-duplicate prediction communities are collapsed, with communities equal-weighted.
- E — the production exact 3–6 model search at the predeclared 0.75-SD search anchor, Top 50 finalists, overlap communities, diversified META.

Each architecture is evaluated natively at PredictionTracker Open, Midweek, and Updated/final on the same chronology and the common verified line-game set. Suspect Open values are excluded rather than replaced.

The architecture headline uses execution k=0 so it measures directional forecasting/selection quality without threshold optimization. A separate 0.00–2.00 SD sweep freezes the architecture within each OOS block and changes only the execution threshold; bet counts are required to be non-increasing as k rises.

Both flat 1u-risk and risk-to-win-1u staking are reported. A deterministic Strategy-E / Updated-line sample at k=0.75 is saved for manual grading audit, and the complementary-side check must exactly swap wins and losses excluding pushes.
